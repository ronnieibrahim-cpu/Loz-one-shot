not do the overworld half of the same task: `check-anchor.mjs`'s own
proof tool rejects any `anchorGate` outside `['d1', 'd2']` by map id, a

item-reuse's own file allowlist does not include — and the token exists

unblocks real objective work sitting right behind it.
